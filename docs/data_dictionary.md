# Data dictionary

## data/interim/dcs_yield_tidy.csv: one row per district × season with a published yield

| column | type | unit | source | notes |
|---|---|---|---|---|
| district | str | – | DCS | upper-case, normalised spelling; 25 administrative districts |
| adm2_pcode | str | – | HDX COD-AB v03 | join key to the boundary polygons (`configs/district_map.csv`) |
| unit_type | str | – | derived | always `district` in this file |
| season | str | – | DCS | `Maha` (planted Oct–Dec, harvested Feb–Apr) or `Yala` (planted Apr–May, harvested Aug–Sep) |
| season_label | str | – | derived | e.g. `2021/22 Maha`, `2022 Yala` |
| season_year | int | year | derived | Maha: start year; Yala: calendar year (see decisions.md) |
| harvest_year | int | year | derived | calendar year of harvest |
| season_order | int | – | derived | 2*harvest_year + (0 Maha, 1 Yala); use this for time ordering and splits |
| yield_kg_ha | float | kg per net ha | DCS Average Yield | **prediction target**; crop-cutting survey estimate, so the label is noisy |
| production_t | float | tonnes | DCS Production (×1000) | row-order defect repaired (decisions.md); missing for 2025/26 Maha |
| sown_ha | float | gross ha | DCS Sown Extent ("Total") | |
| harvested_ha | float | gross ha | DCS Harvested Extent ("Total") | |
| mahaweli_merged | int 0/1 | – | derived | 1 from 2017/18 Maha / 2018 Yala, when Mahaweli H & Udawalawe are included in host districts |

`data/interim/dcs_all_units.csv` has the same columns for every parsed row, including `special_area` (MAHAWELI H, UDAWALAWE), `national` (SRI LANKA) and `highland` (production only).
